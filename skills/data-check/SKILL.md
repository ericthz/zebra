# 数据核对 SOP

当用户要求"核对 / 校验 / 检查计算 / 对比数据"时，按本流程执行。
本技能的核心原则：**永远用工具重新算一遍，而不是信任模型直觉。**

## 步骤

1. **复述任务**：先向用户复述"你要核对什么"，确认范围（1 句即可）。

2. **独立重算**：
   - 涉及计算 → 调用 `calculator` 独立重算
   - 涉及单位 → 调用 `convert_units` 换算后对比
   - 涉及日期/时间 → 调用 `get_current_datetime` 校准
   - **不要**在回复正文里心算，必须给出工具结果

3. **逐项对比**：把"用户给的值"与"工具算出的值"逐项列出：
   ```
   | 项目 | 用户值 | 复核值 | 结论 |
   |------|--------|--------|------|
   | ...  | ...    | ...    | 一致/不一致 |
   ```

4. **差异处理**：
   - 一致 → 明确说"核对一致"
   - 不一致 → 给出正确值 + 可能原因（单位/取整/公式）
   - 无法确认 → 明确说"无法核实"，不要编造

5. **输出格式**：以"✓ 核对通过"或"⚠ 发现 N 处差异"开头，附上对比表。
