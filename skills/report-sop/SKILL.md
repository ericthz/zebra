# 研究报告生成 SOP

当用户要求"写报告 / 写周报 / 总结 / 汇报"时，严格按以下步骤执行。
不要跳步，不要凭记忆编造数据；所有数据必须来自工具调用结果或用户提供。

## 步骤

1. **明确需求**：向用户确认 3 个要素（缺省则用合理默认值）：
   - 主题（默认：用户提问本身）
   - 篇幅（默认：800~1200 字）
   - 受众（默认：非专业读者）

2. **收集事实**（按需调用工具，最多 3 个来源）：
   - 需要网络资料 → `web_search` 搜索
   - 需要当前时间 → `get_current_datetime`
   - 需要数据计算 → `calculator`
   对每个来源记录：来源名 + 结论。

3. **起草结构**（固定骨架，先搭框架再填充）：
   ```
   # 标题
   ## 背景
   ## 核心发现（3~5 条，每条一句话 + 支撑数据）
   ## 分析（对发现的解读，150~300 字）
   ## 建议（3 条可执行建议）
   ## 结论
   ```

4. **撰写正文**：每节控制在 80~200 字；**每个数字必须来自第 2 步的工具结果**。

5. **自检清单**（写完后逐项核对，不满足则重写对应段落）：
   - [ ] 所有数据有来源（工具名 + 时间）
   - [ ] 无"据我所知/大概"这类无依据表述
   - [ ] 结构与骨架一致
   - [ ] 篇幅符合要求
